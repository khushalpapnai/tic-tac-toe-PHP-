# 🕹️ Tic-Tac-Toe Game (PHP, HTML, CSS)

A simple yet interactive Tic-Tac-Toe game built using PHP for backend logic, HTML for structure, and CSS for styling. This two-player game includes win detection, draw handling, and a restart feature.

## 🌐 Live Demo
👉 [Play the Game](http://tic-tac-toe.kesug.com/index.php)

## 🧩 Technologies Used
- **PHP** – Handles game state, win/draw logic, and session management.
- **HTML** – Structures the game board and UI elements.
- **CSS** – Styles the board, buttons, and game messages.

## 🎮 Gameplay Features
- ✅ **Win Detection**: Automatically checks for a winning combination after each move.
- 🤝 **Draw Handling**: Detects when all cells are filled without a winner.
- 🔄 **Restart Option**: Resets the game board and session to start fresh.
- 👥 **Two-Player Mode**: Alternate turns between Player X and Player O.

## 🚀 How to Play
1. Open the game in your browser.
2. Player X starts the game.
3. Click on an empty cell to make a move.
4. The game checks for a win or draw after each move.
5. Use the **Restart** button to reset the board and play again.
